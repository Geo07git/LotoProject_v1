# 🎲 Loto Project v1

Proiect de Machine Learning pentru analiza și predicția numerelor Loto, cu interfață Streamlit.

---

## 📌 Descriere

Acest proiect folosește modele de Machine Learning pentru:
- analiză statistică a numerelor extrase
- generare de predicții bazate pe date istorice
- simulări și backtesting al performanței modelelor

---

## 🚀 Rulare aplicație

Instalare dependințe:
pip install -r requirements.txt

Rulare Streamlit:
streamlit run LotoProject.py

## ⚠️ Notă
Acest proiect este experimental și nu garantează acuratețe în predicții.

## 🧠 Tehnologii folosite
Python
Streamlit
Pandas / NumPy
Scikit-learn
Plotly
